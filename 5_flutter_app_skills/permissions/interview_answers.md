# Ответы: Permissions

**1.** granted/denied/permanentlyDenied/restricted/limited — разные UX.

**2.** permanentlyDenied / повторный deny без диалога — вести в App Settings.

**3.** Объяснить зачем permission до system prompt (особенно Android).

**4.** Частичный доступ; UI должен уметь работать с subset.

**5.** Запрашивать contextual just-in-time — выше convert и доверие.

**6.** FeatureAccess: allowed / needsRequest / needsSettings / unavailable.

**7.** Fake PermissionGateway со статусами.

**8.** Android 13+ отдельное permission для уведомлений.
