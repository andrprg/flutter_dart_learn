# Ответы: Widget Keys

**1.** Сохранять Element/State при перемещении виджета в дереве; корректные анимации/формы/списки.

**2.** ValueKey — по значению (id). ObjectKey — по identity объекта. UniqueKey — всегда новый, сбрасывает state.

**3.** При insert/delete/sort индексы съезжают → State прилипает не к тем данным.

**4.** Доступ к State (`FormState`), измерению, редким случаям. Дорого и ломает инкапсуляцию — не злоупотреблять.

**5.** Базовый тип для Value/Object/Unique — в рамках родителя.

**6.** Нужны стабильные ключи для анимаций перемещения.

**7.** Нет, один GlobalKey — один элемент в дереве.

**8.** Только где важна идентичность при структурных изменениях.
