# Ответы: Map и Set

**1.** `Map` — ключ→значение. `Set` — уникальные элементы. Оба на hash (по умолчанию LinkedHash*).

**2.** Хэш-таблица ищет бакет по hashCode, сравнивает через `==`. Несогласованность — «пропавшие» ключи.

**3.** `[]=` всегда пишет. `putIfAbsent` вычисляет значение только если ключа нет.

**4.** У `LinkedHashMap` (default) — порядок вставки. `HashMap` — нет гарантии.

**5.** `for` + `map[e] = (map[e] ?? 0) + 1` или `fold`.

**6.** `intersection`, `union`, `difference`.

**7.** Опасно: hashCode может измениться, ключ «потеряется». Ключи должны быть immutable value.

**8.** Значение само может быть null (если `V?`). `containsKey` точнее для наличия ключа.
